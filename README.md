# Mint Chat-Manager (ВКонтакте) 🍃

Полнофункциональный чат-менеджер для бесед ВКонтакте на **C# (.NET 8 / ASP.NET Core Web API + Callback API + SQLite)**.

---

## 🔒 1. Защита токена и секретов

Никогда не храните токен в открытом виде в репозитории (git). Бот настроен на чтение чувствительных данных из **переменных окружения (Environment Variables)**:

- `VK_ACCESS_TOKEN` — ваш токен сообщества.
- `VK_SECRET_KEY` — секретный ключ из настроек Callback API ВКонтакте.
- `VK_CONFIRMATION_CODE` — строка подтверждения сервера из настроек Callback API ВКонтакте.

### Запуск локально в PowerShell:
```powershell
$env:VK_ACCESS_TOKEN="vk1.a.ChdOUA-..."
$env:VK_SECRET_KEY="my_secret_key"
$env:VK_CONFIRMATION_CODE="a1b2c3d4"
dotnet run
```

## 💾 2. База данных (Где и какую подключить бесплатно?)

Для чат-менеджера есть три отличных бесплатных варианта:

1. **SQLite (по умолчанию в этом проекте)**:
   - **Где**: Встроена в сам проект (файл `mint_bot.db`).
   - **Сколько времени**: **Навсегда бесплатно**.
   - **Плюсы**: Нулевая задержка (локальный файл), нет ограничений на запросы, не требует настройки сторонних серверов.

2. **Supabase (Managed PostgreSQL)**:
   - **Сайт**: [supabase.com](https://supabase.com)
   - **Тариф**: Free Tier **навсегда** (до 500 МБ хранилища, 50 000 активных пользователей в месяц).
   - *Важно*: Если нет обращений в течение 7 дней, проект засыпает (но бот работает непрерывно, поэтому не уснет).

3. **Neon.tech (Serverless PostgreSQL)**:
   - **Сайт**: [neon.tech](https://neon.tech)
   - **Тариф**: Free Tier **навсегда** (0.5 ГБ данных).

## ☁️ 3. Хостинг и Cloudflare (Keep-Alive и быстрая доставка)

- Бот поддерживает **HTTP Keep-Alive** на веб-сервере Kestrel (до 120 секунд), благодаря чему сетевое соединение между Cloudflare и сервером не разрывается, снижая задержку (ping) до минимума.
- Рекомендуется использовать **Cloudflare Tunnel (cloudflared)** — это позволяет запустить бота на любом VPS или даже домашнем ПК без белого IP и проброса портов с защитой от DDoS:
  ```bash
  cloudflared tunnel --url http://localhost:5000
  ```
  Полученный HTTPS-адрес указывается в настройках Callback API группы ВК: `https://your-tunnel.trycloudflare.com/api/callback`.

## 👑 4. Иерархия должностей в беседах

Должности действуют **локально в рамках конкретной беседы**:
7. **Владелец беседы** (Уровень 7)
6. **Руководитель беседы** (Уровень 6)
5. **Главный администратор** (Уровень 5)
4. **Старший администратор** (Уровень 4)
3. **Администратор** (Уровень 3)
2. **Старший модератор** (Уровень 2)
1. **Модератор** (Уровень 1)
0. **Пользователь Mint** (Уровень 0)

## 🛠️ 5. Список реализованных команд

| Команда | Мин. роль | Описание |
|---|---|---|
| `/ping` | Пользователь | Проверка задержки и времени отклика сервера (с reply) |
| `/stats` | Пользователь | Карточка статистики пользователя, должности, варнов и сообщений |
| `/q` | Пользователь | Самокик из беседы (со сбросом роли и ника до обычного пользователя) |
| `/help` | Пользователь | Справка по всем командам чат-менеджера |
| `/id` | Пользователь | VK ID и дата регистрации аккаунта через `regvk.com` |
| `/minfo` | Модератор | Детальная информация о должности и назначившем администраторе |
| `/mute` | Модератор | Временная блокировка чата (пример: `/mute [ссылка] 1h спам`) с удалением сообщений |
| `/unmute` | Модератор | Снятие блокировки чата |
